### 1.2.1 Définition d'un Système d'Information (SI)

:::retenir Définition officielle
Un **Système d'Information (SI)** est l'ensemble organisé des **ressources** (personnes, données, procédures, matériels, logiciels) qui permettent de **collecter, stocker, traiter et diffuser** l'information au sein d'une organisation.
:::

Le SI assure une passerelle permanente entre le terrain opérationnel et les décisions stratégiques :
- Il capte les **données** générées par les activités quotidiennes sur le terrain ;
- Il les transforme en **informations** exploitables pour la direction ;
- Il répercute les **décisions et ordres** de la direction vers les équipes opérationnelles.

---

### 1.2.2 Définition d'un Système Informatique

Un **système informatique** est l'ensemble des **équipements matériels** et des **programmes logiciels** qui assurent le traitement automatisé des données : ordinateurs, serveurs, routeurs, câblage réseau, systèmes d'exploitation, bases de données et progiciels.

Le système informatique représente donc **la partie technique** du Système d'Information. Il n'en constitue en aucun cas la totalité.

```text
+-------------------------------------------------------------+
|                SYSTÈME D'INFORMATION (SI)                   |
|                                                             |
|   [ Personnes ]       [ Procédures ]       [ Données ]      |
|                                                             |
|         +-------------------------------------+             |
|         |        SYSTÈME INFORMATIQUE         |             |
|         |                                     |             |
|         |    [ Matériel ]      [ Logiciels ]  |             |
|         |    [ Réseaux  ]      [ Bases BDD ]  |             |
|         +-------------------------------------+             |
+-------------------------------------------------------------+
```

---

### 1.2.3 Tableau comparatif : Système d'Information vs Système Informatique

| Critère | Système Informatique | Système d'Information |
|---|---|---|
| **Nature** | Matériel électronique et programmes logiciels | Ressources techniques **ET humaines**, données, règles de gestion et procédures |
| **But** | Traiter automatiquement des flux de données | Faire circuler l'information utile à la bonne personne, au bon moment |
| **Périmètre** | Sous-ensemble technique du SI | Englobe l'organisation humaine et les outils |
| **Sans ordinateur ?** | **Impossible** | **Possible** (registres manuels, fiches papier, tableaux d'affichage) |

:::attention Le piège classique
Confondre le SI avec le logiciel informatique. Acheter un progiciel très cher ne garantit absolument pas d'avoir un bon SI si les procédures de travail sont floues ou si les utilisateurs refusent de l'alimenter.
Au Centre Avenir Formation, un SI existait déjà (fiches papier, cahier d'écolier, fichiers Excel) ; ce qui manquait, c'était un système informatique cohérent et partagé.
:::

### 1.2.4 Les 4 fonctions universelles d'un SI

Quelle que soit la taille de l'organisation, un SI remplit quatre fonctions incontournables :

1. **Collecter** : recueillir les données brutes là où elles naissent (saisie de la fiche d'inscription par le candidat ou le secrétariat).
2. **Stocker** : conserver les données de façon durable, fiable, sécurisée et retrouvable (base de données relationnelle).
3. **Traiter** : calculer, ordonner, recouper et agréger les données (calcul des moyennes, contrôle des seuils de paiement).
4. **Diffuser** : restituer l'information sous la bonne forme au destinataire légitime (édition du bulletin, notification par e-mail).

---

### 1.2.5 Les 5 composantes du SI

Un SI équilibré repose sur cinq piliers indissociables :
- **Personnes** : celles qui saisissent, exploitent, décident et administrent (secrétaire, comptable, formateur, directeur) ;
- **Procédures** : règles métier définissant les étapes du travail (comment s'inscrire, qui valide les bourses) ;
- **Données** : ensemble des entités mémorisées (coordonnées des apprenants, relevés de notes, quittances) ;
- **Logiciels** : applications applicatives, SGBD et interfaces utilisateur ;
- **Matériel et réseau** : postes de travail, serveurs, imprimantes, pare-feu et accès Internet.

---

### 1.2.6 Les grandes familles de Systèmes d'Information

On classe les SI selon la nature des besoins organisationnels couverts :

| Famille | Rôle principal | Exemple type |
|---|---|---|
| **SI Opérationnel** | Enregistrer et exécuter les opérations quotidiennes de routine | Enregistrer une inscription, éditer un reçu de paiement |
| **SI de Gestion** | Suivre, contrôler et piloter l'activité à court/moyen terme | Tableau de bord mensuel des impayés par filière |
| **SI d'Aide à la Décision (SIAD)** | Simuler des scénarios, analyser des tendances prospectives | Faut-il ouvrir une nouvelle filière de cybersécurité ? |
| **SI Intégré (ERP / PGI)** | Fédérer l'ensemble des services autour d'une **base de données unique** | Progiciel unique partagé entre scolarité, comptabilité et RH |

:::retenir ERP / PGI
**ERP** (*Enterprise Resource Planning*) ou **PGI** (*Progiciel de Gestion Intégré*) : logiciel modulaire unique articulé autour d'une **base de données partagée**. Lorsqu'une facture est validée par la scolarité, elle est instantanément visible par le service comptable sans aucune ressaisie.
:::
